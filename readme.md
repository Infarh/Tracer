# Tracer

Легковесная консольная утилита для трассировки маршрута до хоста или IP-адреса.

`Tracer` отправляет ICMP-запросы с последовательно увеличивающимся TTL и показывает:
- узлы маршрута;
- усредненное время отклика на каждом узле;
- DNS-имя узла (если доступно).

## Возможности
- Трассировка до доменного имени или IP-адреса
- Разрешение доменного имени в IPv4-адрес
- Параллельный сбор RTT и reverse DNS для ускорения вывода
- Вывод в табличном формате с номерами TTL
- Встроенное самообновление из GitHub Releases

## Требования
- .NET SDK/Runtime 9.0 (для запуска из исходников)
- Доступ к ICMP в вашей среде выполнения
- Для обновления: доступ в интернет к GitHub API и Releases

## Запуск

### Из проекта
```powershell
dotnet run --project Tracer -- ya.ru
```

### С готовым бинарным файлом
```powershell
tracer.exe ya.ru
```

Если аргумент не передан, по умолчанию используется хост `ya.ru`.

## Ключи командной строки
- `-v` - вывести текущую версию приложения
- `--update` или `--upgrade` - проверить наличие новой версии и запустить обновление

Примеры:
```powershell
tracer.exe -v
tracer.exe --update
tracer.exe 8.8.8.8
tracer.exe github.com
```

## Пример вывода
```text
Trace route to ya.ru [77.88.55.242]
════╤═════════╤═════════════════╤════════════════════════════════════════
ttl │ ping    │ ip-address      │ host name
────┼─────────┼─────────────────┼────────────────────────────────────────
  1 │    1 ms │ 192.168.0.1     │
  2 │    5 ms │ 10.0.0.1        │ gw-1.example.net
  3 │   12 ms │ 203.0.113.10    │ edge-01.example.net
  4 │ ---- ms │ 203.0.113.20    │
  5 │   18 ms │ 77.88.55.242    │ ya.ru
════╧═════════╧═════════════════╧════════════════════════════════════════
End.
```

`ping` - среднее значение по нескольким ICMP-запросам. `---- ms` означает, что измерить RTT не удалось.

## Обновление
При запуске с `--update`/`--upgrade` приложение:
1. Получает последнюю версию из `https://api.github.com/repos/Infarh/Tracer/releases/latest`
2. Сравнивает ее с локальной версией
3. Скачивает новый `.exe`, если версия новее
4. Запускает `updater.bat` для замены текущего файла

Рядом с исполняемым файлом могут появляться:
- резервная копия `.bak`
- временный файл новой версии `*[version].new.exe`
- служебный лог `update.log`

## Публикация
Для публикации используется скрипт:
```powershell
./Tracer/publish.bat
```

Он вызывает `dotnet publish` c профилем `Properties/PublishProfiles/FolderProfile.pubxml`.
