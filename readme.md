# Tracer

## Описание проекта
`Tracer` — это консольное приложение на C#, предназначенное для выполнения трассировки маршрута до указанного хоста или IP-адреса. Программа использует ICMP-запросы (ping) для определения маршрута и отображает информацию о каждом узле на пути.

## Основные возможности
- Определение IP-адреса хоста по его имени.
- Выполнение последовательных ICMP-запросов с увеличением значения TTL (Time To Live).
- Отображение средней задержки (ping) для каждого узла.
- Получение имени хоста для каждого IP-адреса (если доступно).
